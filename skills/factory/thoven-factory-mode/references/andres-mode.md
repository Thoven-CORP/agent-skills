# Andres mode (pointer)

Factory mode does not restate Andres's product-session rules.

When a factory ticket needs any of these, load `skills/andres-mode/SKILL.md` and follow it.

- Linear and the tldraw board as the only records
- Spec parity by decision id
- Visual parity on the real page
- Show, then ask
- One verify cadence (`skills/dev/verify/SKILL.md`)

Factory loop limits, forbidden areas, and the station 6 prompt stay in this folder and in `skills/factory/factory-rules/`.
