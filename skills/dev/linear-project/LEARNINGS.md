# Learnings — linear-project

A running log of what went wrong in real use and what changed because of it. **Read this before
editing SKILL.md.** New entries go on top. Keep each one to: what happened, why, what changed.

---

## 2026-11-12 — a feature has an end; the front page is one screen

**What changed.** Setup puts a feature Project in an Initiative, chooses three to five stages plus Follow-ups, opens the description with "Where we are", and routes ongoing work to a standing Project.
**Why.** Projects grew too long to read, and tickets floated with no Project.
**More.** `releases/2026-11-12-linear-system.md`

## 2026-11-12 — setup creates the three documents

**What changed.** Setup now creates the Spec, Architecture and Log from their Linear templates for a Project that builds across tickets. The brief's "Key decisions" section became "Open setup questions".
**Why.** "Do not create document templates" left every spec page a blank page.
**More.** `releases/2026-11-12-instructions-rewrite.md`
