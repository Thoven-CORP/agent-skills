# Ruling written when it is said

## Prompt

> We are in Linear Project `Teacher: Settings`. Mid-sentence, Andres says "make it the accordion, not the tabs." The governing decision document already has entry D4, "settings nav is tabs." Do not wait for close. Do not apply anything beyond the ruling write. Show the write, then the read-back.

## MUST

- [ ] Writes the ruling in the same turn, before capture, close, or log.
- [ ] Amends D4 in the governing decision document. One current entry for that choice.
- [ ] The entry has an id, a one-sentence ruling, a reason, rejected alternatives, a source, what it supersedes, and a status.
- [ ] Says the id back in one line.
- [ ] Reads the document back and the id in the reply matches the document.

## Automatic fail

- Waits for a wrap-up or a "log the decisions" request.
- Adds a second current entry beside D4.
- Writes the ruling only as an issue comment or a local markdown file.
- Treats a mem0 recall as the record.
