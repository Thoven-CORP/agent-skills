# When to parallelize

Read this when Meta is choosing a next room. Independent items get their own
Work tab. Dependent items stay on the fat card as checkboxes.

## Dashboard

Notifications can implement while Meta stays on Upcoming. Different surfaces,
different owners, no shared proto. Two rooms.

A filter-bar motion pass and the notification empty state share the same panel.
One room.

## Onboarding

The first-run panel is one flow. Step 2 does not start in a second pane while
step 1 is still being ruled. Checkboxes on the fat card.

Stripe-waiting copy in Business is a different surface. That can be a room
once the panel's contract is locked.

## Business

Pricing, Payments, Profile, Reviews are four tabs of one section. Parallelize
a tab only after the section frame exists and that tab's DESIGN row is ruled.
The frame is the fat card. A tab is a room.

## The test

If two agents can finish without editing the same file or waiting on the same
ruling, parallelize. If one output is the other input, keep it on the card.
